# 뒷공부 근절 캠페인

서로의 뒷공부를 감시하는 실시간 타이머. 방을 만들고 링크를 뿌리면 같은 방 사람끼리 얼굴과 뒷공부 시간을 서로 감시합니다.

## 실행

```
npm install
npm start
```

`http://localhost:3000` 접속. Node 20.12 이상 필요.

## 후원(결제)

토스페이먼츠 연동. 기본값은 테스트 키라 실제 출금은 없습니다. 실결제는 `.env.example`을 `.env`로 복사해 라이브 키(`live_ck_`, `live_sk_`)를 넣으세요.

실시간 연결(WebSocket)이 필요하므로 Vercel 같은 정적 호스팅이 아니라 Node 서버를 띄울 수 있는 곳(Render, Railway 등)에 배포해야 합니다.
